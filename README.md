# 轻体记

一个面向减脂用户的轻量身体记录 App 概念 Demo。

## 在线体验方式

下载仓库后，直接双击打开 `fit-demo.html`。

## Demo 功能

- 月历展示晨起空腹体重
- 体脂秤截图 OCR 交互演示
- 每日身体数据与体型照片记录
- 体重、体脂趋势
- 两日期体型照片对比
- AI 体型初评与用户确认
- AI 每周计划和健身房动作 To-do
- 雾樱与曜石双主题切换
